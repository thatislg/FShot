# Bảng đặc tả yêu cầu SRS (F-Shot trên Windows)

**Ký hiệu mức độ ưu tiên:**

- **M (Must have):** Bắt buộc cho MVP.
- **S (Should have):** Cần thiết cho bản v1.0.
- **C (Could have):** Tiện ích bổ sung / Tùy chọn nâng cao.
- **I (Imgur):** Phụ thuộc tính năng Upload đám mây.

### 6. Bảng yêu cầu phi chức năng (NFR)

| **Mã**     | **Tiêu chuẩn**             | **Chỉ số đo lường định lượng**                               | **Kiểm chứng**               |
| ---------- | -------------------------- | ------------------------------------------------------------ | ---------------------------- |
| **NFR-01** | **Tần số quét render**     | Tốc độ vẽ trên canvas đạt ổn định **$\ge$ 60 FPS** (120 FPS trên màn hình cao cấp). | SkiaSharp FPS Counter        |
| **NFR-02** | **Độ trễ phản hồi**        | Thời gian đóng băng và mở overlay toàn màn hình **$<$ 100 ms** từ khi bấm hotkey. | Stopwatch profiling          |
| **NFR-03** | **Độ sắc nét hiển thị**    | Không bị nhòe pixel, không lệch tọa độ con trỏ trên thiết lập màn hình đa tỉ lệ (Mixed DPI: 100%, 125%, 150%). | Multi-monitor Rig Testing    |
| **NFR-04** | **Chiếm dụng tài nguyên**  | RAM chạy ngầm **$<$ 35 MB**; RAM khi kích hoạt vẽ overlay **$<$ 120 MB**. | Windows Task Manager         |
| **NFR-05** | **Tính bất khả đảo ngược** | Thuật toán `Pixelate` phải hủy triệt để pixel gốc trên mảng byte, ngăn việc khôi phục text qua AI/OCR. | Security audit trên ảnh xuất |
