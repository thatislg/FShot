## 3. Lỗi đã fix

### 3.1 Build lỗi do commit thêm toolbar action

**Nguyên nhân:** `ExecuteStartExport` dùng API clipboard cũ (`SetDataAsync("PNG", bytes :> obj)`) không tồn tại trong Avalonia 12.1.2; `Dispatcher.UIThread.InvokeAsync` trả về `DispatcherOperation`, không phải `Task`, gây cascade type mismatch trong `async { }`.

**Fix:**
- Thay clipboard call bằng `DataTransfer`/`DataTransferItem` với `DataFormat.CreateBytesPlatformFormat("PNG")`.
- Thay `InvokeAsync(...)` + `Async.AwaitTask` bằng `Dispatcher.UIThread.Post(...)` cho `ExportCompleted` dispatch.

### 3.2 Degrade: sau khi vẽ, xóa capture region nhưng annotation vẫn còn

**Nguyên nhân:** Không phải logic bị xóa. Fix gốc (commit `5f34267`) vẫn còn trong `OverlayState.fs`: khi có annotations và click ngoài vùng chọn, phát `StartExport CopyToClipboard` rồi đóng overlay. Tuy nhiên, do `FShot.UI` build lỗi, binary chạy trên máy là build cũ từ 9h sáng, chưa có cả fix annotation lifecycle lẫn toolbar action.

**Fix:** `dotnet clean` + sửa lỗi compile + rebuild. Regression test `Selected PointerPressed ngoài vùng khi đã có annotations trigger Copy and CloseOverlay` vẫn pass.

## 4. Hành vi hiện tại

- Toolbar hiển thị 15 nút: 10 annotation tool + 5 action (Undo, Redo, Copy, Save, Cancel).
- Action buttons chỉ active khi đang ở trạng thái `Selected` và không đang vẽ annotation.
- **Undo/Redo**: dựa trên `HistoryStack.CanUndo` / `CanRedo`; icon disabled khi không thể undo/redo.
- **Save**: mở save dialog, đề xuất `fshot_capture.png`, hỗ trợ PNG/JPG, render crop theo vùng chọn.
- **Copy**: đưa PNG bytes vào clipboard qua Avalonia `IClipboard.SetDataAsync`.
- **Cancel**: hủy vùng chọn và đóng overlay.
- Sau export thành công với `Config.CloseAfterExport = true`, overlay tự động đóng.
