## 3. Bug đã fix

### 3.1 Icon bị lệch khỏi toolbar (~2 cm về góc trên-trái)

**Nguyên nhân:** Thứ tự nhân transform matrix sai. Code cũ dùng `translateMatrix * scaleMatrix`, khiến vector translate cũng bị nhân với `scale = 0.75`, đẩy icon ra xa khỏi vị trí button.

**Fix:** Đổi thành `scaleMatrix * translateMatrix` để scale trước, translate sau, icon nằm chính giữa button.

```fsharp
// Cũ (sai):
context.PushTransform(translateMatrix * scaleMatrix)

// Mới (đúng):
context.PushTransform(scaleMatrix * translateMatrix)
```

### 3.2 Icon không có màu, chỉ hiện trắng/xanh

**Nguyên nhân:** Mỗi tool dùng màu fill/stroke khác nhau từ bảng màu semantic, nhưng trên nền toolbar kem trắng một số màu nhạt bị chìm hoặc tông trắng gây mất khối.

**Fix:** Đồng nhất icon mặc định thành `Core.DarkWalnut` `#3D2B1F` theo token `ToolButton.Default.IconColor`; active tool chuyển sang trắng `#FFFFFF`. Fill alpha 80%, stroke alpha 90% để tạo chiều sâu.
