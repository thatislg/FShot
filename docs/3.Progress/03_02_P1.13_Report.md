# Báo cáo P1.13: Công cụ vẽ đường thẳng (Line)

> Ngày cập nhật: 2026-09-14

## 1. Tóm tắt

Hoàn thành triển khai công cụ Line cho phép người dùng vẽ đoạn thẳng trên overlay, bắt đầu từ điểm nhấn chuột đến điểm thả chuột, hiển thị preview trong lúc kéo. Thiết kế tham chiếu: `docs/2.Design/04_Annotation/04_04_LineAndArrow.md`.

## 2. Phần đã triển khai

### 2.1. Core domain

- **File:** `src/FShot.Core/Domain/Annotation.fs`
- `Tool.Line of start: Point * endPoint: Point` đã được định nghĩa từ P1.01.
- `Annotation.BoundingBox` xử lý `Tool.Line` qua công thức bounding box từ hai điểm.

### 2.2. Overlay State Machine

- **File:** `src/FShot.Core/State/OverlayState.fs`
- `buildTool` đã tạo `Tool.Line(start, current)` khi `CurrentTool = LineTool`.
- `DrawingPreview(start, current, LineTool)` được cập nhật trên `PointerMoved` và commit thành annotation trên `PointerReleased`.
- Không cần thay đổi state machine vì luồng này đã được tổng quát hóa từ P1.03.

### 2.3. Rendering.Skia

- **File:** `src/FShot.Rendering.Skia/Renderers/AnnotationRenderer.fs`
- Bổ sung nhánh `Tool.Line` dùng `SKCanvas.DrawLine` từ điểm bắt đầu sang điểm kết thúc, với màu và độ dày từ `AnnotationStyle`.
- Tái sử dụng `DomainToSkia.createStrokePaint` và `pointToSkPhysical` để đảm bảo nhất quán với Pencil.

### 2.4. UI layer

- **File:** `src/FShot.UI/SkiaCanvas/CaptureCanvas.axaml.fs`
- Refactor logic vẽ annotation: tách `annotationPen` và `avPoint` để dùng chung cho mọi công cụ (DRY).
- Bổ sung nhánh `Tool.Line` trong `drawAnnotation`, vẽ cả annotations đã commit và preview bằng `context.DrawLine` của Avalonia.
- Toolbar tạm vẫn giữ nhãn `L` cho `LineTool`; phím tắt `L` đã hoạt động từ P1.12.

### 2.5. Cập nhật thiết kế

- **File:** `docs/2.Design/04_Annotation/04_04_LineAndArrow.md`
- Thêm mục 1.3 mô tả preview và commit: preview là đoạn thẳng từ điểm bắt đầu đến vị trí con trỏ hiện tại; commit tạo `Line(A, C)`.

### 2.6. Tests

- **File:** `tests/FShot.Rendering.Skia.Tests/AnnotationRendererTests.fs`
  - Refactor helper `createAnnotation` để tạo annotation với bất kỳ `Tool` nào.
  - Thêm test `Line render vẽ ít nhất một pixel màu xanh`.
  - Thêm test `Line điểm trùng nhau không gây lỗi`.
- **File:** `tests/FShot.Core.Tests/State/OverlayStateTests.fs`
  - Củng cố test `Annotating PointerReleased commit và push history` để assert tool commit là `Tool.Line` với đúng hai điểm.

## 4. Các vấn đề còn lại / cần làm tiếp

- Toolbar vẫn là chữ cái tạm thời, chưa thay bằng icon Flameshot.
- Phím tắt `L` dùng `e.Key` còn là tech debt do bộ gõ tiếng Việt; cần xử lý đúng key binding sau này.
- Các tool còn lại (Arrow, Rectangle, Circle, Marker, Text, Pixelate) chưa có renderer trong UI.
