## 3. Lỗi đã gặp và cách khắc phục

### 3.1 Lỗi compile: `OverlayResult.History` không tồn tại

- **Biểu hiện:** `error FS0039: The type 'OverlayResult' does not define the field, constructor or member 'History'`.
- **Nguyên nhân:** Test mới cho Circle dùng `result.History.Current.Annotations` thay vì `result.State.History.Current.Annotations`.
- **Khắc phục:** Sửa 4 dòng trong `OverlayStateTests.fs` để lấy `State` trước khi truy cập `History`.

### 3.2 Lỗi compile: `Tool.Arrow` nhận `ArrowStyle` thay vì `bool`

- **Biểu hiện:** `error FS0001: This expression was expected to have type 'ArrowStyle' but here has type 'bool'`.
- **Nguyên nhân:** Helper `createArrowAnnotation` trong renderer test truyền `false` làm style.
- **Khắc phục:** Đổi thành `ArrowStyle.Standard`.
