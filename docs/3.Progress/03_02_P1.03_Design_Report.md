## 1. Mục tiêu

Hoàn thiện thiết kế máy trạng thái cho cửa sổ overlay tương tác trong F-Shot. State machine phải:

- Điều phối toàn bộ vòng đời phiên chụp: từ mở overlay, tạo vùng chọn, vẽ chú thích, đến xuất ảnh.
- Tách biệt hoàn toàn khỏi UI framework và rendering.
- Trả về dữ liệu để UI vẽ lại scene sau mỗi sự kiện.
- Không chứa side effect; UI layer chịu trách nhiệm thực hiện các commands.

## 3. Quyết định thiết kế chính

### 3.1 Các trạng thái chính

- **Idle**: overlay vừa mở, phủ tối toàn màn hình, chưa có vùng chọn.
- **Selecting**: đang kéo chuột để tạo vùng chọn.
- **Selected**: vùng chọn đã cố định, hiển thị 8 điểm neo và toolbar.
- **Annotating**: đang vẽ một annotation hoặc nhập text.
- **Exporting**: đang thực hiện xuất ảnh.

### 3.2 Sub-states

- **MovingSelection**: kéo vùng chọn di chuyển.
- **ResizingSelection**: kéo điểm neo để co giãn vùng chọn.
- **EditingText**: nhập văn bản qua TextBox tạm thời.

### 3.3 Mô hình Annotating trong triển khai

- **DefaultTool**: `SelectionTool` — cho phép di chuyển vùng chọn bằng chuột. Khi chuyển sang `LineTool`, `ArrowTool`, `RectangleTool`, `CircleTool`, `PencilTool`, `MarkerTool`, `TextTool`, `PixelateTool`, nhấn chuột trong vùng chọn bắt đầu vẽ annotation.
- **Annotating**: được mô hình hóa bằng `AnnotationInteraction` khác `NoAnnotation`, trong khi `Selection.State` vẫn giữ `Selected`. Cách này giảm số lượng trạng thái chính mà vẫn đảm bảo hành vi đúng.

### 3.3 Input events

State machine nhận các sự kiện đã được UI đóng gói sẵn:

- PointerPressed, PointerMoved, PointerReleased.
- KeyDown cho Esc, Enter, mũi tên, Ctrl+Z, Ctrl+Y, Ctrl+C, Ctrl+S.
- Tool commands: SelectTool, SetColor, SetStrokeWidth, SetFontSize.
- Action commands: Undo, Redo, Copy, Save, Accept, Cancel.
- Lifecycle commands: OpenOverlay, CloseOverlay, ExportCompleted.

### 3.4 Output

Sau mỗi sự kiện, state machine trả về:

- RenderModel mới để UI vẽ lại scene.
- Các commands cần UI thực hiện: CloseOverlay, ShowTextBox, StartExport, v.v.

### 3.5 Tích hợp với các module khác

- **Selection Engine**: tính toán vùng chọn, di chuyển, co giãn.
- **Annotation Engine**: tạo và cập nhật preview, chuyển preview thành annotation commit.
- **HistoryStack**: lưu snapshot sau mỗi commit annotation; undo/redo theo phím tắt.
- **Export Service**: thực hiện xuất ảnh.
- **UI Layer**: thu thập input, vẽ scene, thực hiện commands.

## 4. Những điểm cần quyết định trước khi viết code

| Câu hỏi | Khuyến nghị tạm thời |
|---------|---------------------|
| Có tách Moving/Resizing thành state riêng không? | Giữ là sub-state của `Selected` để giảm độ phức tạp. |
| UI gửi raw events hay commands? | UI gửi commands có ngữ nghĩa, không gửi raw events. |
| State machine trả về RenderModel hay UI tự tính? | State machine trả về RenderModel đầy đủ. |
| Có đóng overlay sau khi copy không? | Theo cấu hình; MVP mặc định đóng sau copy. |
| Vùng chọn quá nhỏ khi thả chuột thì sao? | Quay về `Idle`, ngưỡng tối thiểu khoảng 8x8 pixel. |

## 5. Liên kết với các phần khác

- **Geometry:** cung cấp Point, Rect, clamp.
- **Capture:** CaptureResult làm nền cho RenderModel.
- **Selection:** Selection Engine tính toán vùng chọn.
- **Annotation:** Annotation Engine tạo preview và commit.
- **History:** HistoryStack lưu snapshot khi commit.
- **Export:** Export Service xuất ảnh từ RenderModel.
- **Config:** cung cấp công cụ, màu, độ dày mặc định.
- **Rendering.Skia:** vẽ RenderModel.
- **UI/Avalonia:** gửi events, nhận RenderModel, thực hiện commands.
