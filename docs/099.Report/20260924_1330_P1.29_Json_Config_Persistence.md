## 1. Tóm tắt công việc

Triển khai hoàn chỉnh cơ chế nạp và lưu trữ cấu hình người dùng từ file JSON đặt tại `%APPDATA%\FShot\config.json` theo đúng đặc tả của P1.29:

- **Tự động tạo file:** Lần đầu khởi động, nếu thư mục hoặc file cấu hình chưa tồn tại, ứng dụng tự động khởi tạo với cấu hình chuẩn và định dạng indented JSON dễ đọc.
- **Dữ liệu cấu hình MVP:** Hỗ trợ đầy đủ các trường `savePath`, `filenamePattern`, `drawColor`, `drawThickness`, `defaultTool`, `closeAfterExport`.
- **Khả năng chịu lỗi cao (Robust Fallback):** Nếu file JSON rỗng, lỗi cú pháp hoặc bị thiếu trường, hệ thống tự động điền các giá trị mặc định mà không gây crash app.
- **Tích hợp sâu:** Áp dụng màu vẽ, độ dày nét, công cụ mặc định và tùy chọn lưu file trực tiếp vào `OverlayState` và quy trình chụp headless.

### 2.2 Domain Model & Tuần tự hóa JSON
File `src/FShot.Core/Domain/Config.fs`:
- Định nghĩa record `AppConfig` với các trường:
  - `SavePath: string` (mặc định `""`)
  - `FilenamePattern: string` (mặc định `"fshot_%Y-%m-%d-%H%M%S"`)
  - `DrawColor: string` (mặc định `"#FF0000"`)
  - `DrawThickness: float` (mặc định `2.0`)
  - `DefaultTool: string` (mặc định `"SelectionTool"`)
  - `CloseAfterExport: bool` (mặc định `true`)
- Phương thức `Normalized()`: làm sạch chuỗi, clamp độ dày nét trong `[1.0, 50.0]`, fallback màu hex và tên công cụ hợp lệ.
- Chuyển đổi 2 chiều: `ToSnapshot(): ConfigSnapshot` và `AppConfig.FromSnapshot(snapshot)`.
- Bộ chuyển đổi `AppConfigJsonConverter` và mô-đun `ConfigJson`: hỗ trợ case-insensitive, camelCase naming policy, indented format, và tự động bù đắp giá trị mặc định cho các trường bị thiếu trong JSON.

### 2.3 Win32 FileStore
File `src/FShot.Platform.Win32/Config/ConfigStore.fs`:
- Phân giải đường dẫn `%APPDATA%\FShot\config.json`.
- `loadConfigFrom`, `saveConfigTo`: nạp và lưu file từ đường dẫn cụ thể (hỗ trợ test).
- `loadConfig`, `saveConfig`: thao tác trực tiếp trên đường dẫn mặc định của hệ thống.
- `loadSnapshot`, `loadSnapshotFrom`: chuyển đổi trực tiếp sang `ConfigSnapshot` phục vụ overlay.

### 2.4 Tích hợp UI & App Lifecycle
- `src/FShot.UI/Program.fs`:
  - Nạp cấu hình ngay tại điểm vào `main` và gán vào `App.ConfigSnapshot`.
  - Ghi log thông số cấu hình đã nạp.
  - Sử dụng chất lượng nén `NormalizedJpegQuality` từ cấu hình cho chế độ chụp headless.
- `src/FShot.UI/App.axaml.fs`:
  - Khai báo thuộc tính tĩnh `App.ConfigSnapshot`.
  - Khởi tạo và nạp cấu hình khi app hoàn tất khởi động framework.
  - Truyền `App.ConfigSnapshot` vào cửa sổ `CaptureOverlayWindow`.
- `src/FShot.UI/Windows/CaptureOverlayWindow.axaml.fs`:
  - Bổ sung thuộc tính `ConfigSnapshot`.
  - Khởi tạo `OverlayStateLogic.init` bằng `this.ConfigSnapshot`.

### 3.2 Nghiệm thu runtime thực tế trên Windows

1. **Khởi tạo tự động:**
   - Xóa file cấu hình cũ và chạy lệnh `fshot full -c`.
   - Kết quả: File `%APPDATA%\FShot\config.json` được tự động tạo với nội dung:
     ```json
     {
       "savePath": "",
       "filenamePattern": "fshot_%Y-%m-%d-%H%M%S",
       "drawColor": "#FF0000",
       "drawThickness": 2,
       "defaultTool": "SelectionTool",
       "closeAfterExport": true
     }
     ```

2. **Áp dụng cấu hình tùy chỉnh:**
   - Sửa file `config.json` với các giá trị: `drawColor = "#38BDF8"`, `drawThickness = 6.5`, `defaultTool = "ArrowTool"`, `savePath = "D:\ScreenshotsTest"`, `closeAfterExport = false`.
   - Khởi chạy app và kiểm tra log tại `%TEMP%\FShot\logs\FShot_Current.log`:
     ```text
     [12:56:43.443] Main entry: Config loaded: Tool=ArrowTool, Color=#38BDF8FF, Thickness=6.5, SavePath=Some "D:\ScreenshotsTest", Close=false
     ```
   - Xác nhận: Ứng dụng đã nhận chính xác các thiết lập tùy biến từ file JSON.
