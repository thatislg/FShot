## 1. Tóm tắt công việc

Triển khai hoàn chỉnh thông báo desktop cho các sự kiện:

- Save ảnh thành công (kèm tên file).
- Copy ảnh vào clipboard thành công.
- Hủy thao tác chụp (khi `showAbortNotification = true`).

Thay vì dựa vào Windows Toast API hay Win32 `Shell_NotifyIcon` balloon — cả hai đều dễ bị chặn khi app chạy nền/daemon hoặc thiếu AUMID/Start Menu shortcut — F-Shot giờ tự vẽ một cửa sổ Avalonia nhỏ ở góc màn hình. Cửa sổ này hiển thị rõ trên mọi nền, tự đóng sau ~4 giây, click để đóng, và click khi save sẽ mở Explorer highlight file.

## 2. Chi tiết thay đổi mã nguồn

### 2.1 UI Notification Window
- `src/FShot.UI/Windows/NotificationWindow.axaml`:
  - Cửa sổ 320x80, không viền (`CanResize="False"`), `ShowInTaskbar="False"`, `Topmost="True"`.
  - Nền đặc `#FF222222`, viền `#55FFFFFF`, bo góc 8.
  - Icon 📸, title trắng, message xám `#CCCCCC`.
- `src/FShot.UI/Windows/NotificationWindow.axaml.fs`:
  - Định nghĩa `NotificationKind` (CaptureSuccess, CopySuccess, CaptureAborted).
  - `NotificationService` mở/đóng `NotificationWindow`, tôn trọng `enabled` và `force`.
  - Cửa sổ tự động định vị góc dưới phải màn hình chính (`Screens.Primary.WorkingArea`).
  - Tự động đóng sau 4 giây; click vào thông báo đóng ngay.
  - Click khi có đường dẫn save sẽ gọi `NotificationService.HighlightFileInExplorer(path)`.

### 2.2 Tích hợp App Lifecycle
- `src/FShot.UI/App.axaml.fs`:
  - Khởi tạo `NotificationService` từ `FShot.UI.Services`.
  - Subscribe `CaptureCanvasEvents.ExportCompleted` (Saved/Copied/Failed) để phát thông báo `showDesktopNotification`.
  - Subscribe `CaptureCanvasEvents.AbortRequested` để phát thông báo `showAbortNotification` trong daemon mode.
  - Dispose cửa sổ thông báo khi app thoát.

### 2.3 Dọn dẹp Win32 Notification cũ
- `src/FShot.Platform.Win32/Notifications/NotificationService.fs`:
  - Loại bỏ toàn bộ logic Win32 Balloon/Toast (`WNDCLASSEX`, `RegisterClassEx`, `Shell_NotifyIcon`, `Microsoft.Toolkit.Uwp.Notifications`).
  - Giữ lại module helper `NotificationHelper.highlightFileInExplorer` để dùng chung với UI service.

### 2.4 Unit tests
- `tests/FShot.UI.Tests/NotificationServiceTests.fs`:
  - Kiểm tra `buildContent` trả về đúng title/message/filePath.
  - Kiểm tra `ShowNotification` tôn trọng `enabled`/`force`.
  - Kiểm tra `HighlightFileInExplorer` trả về false khi file không tồn tại.
  - Kiểm tra `Dispose` không throw.
